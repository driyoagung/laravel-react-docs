# Ebook Next.js 14

Dokumentasi Next.js 14 dalam Bahasa Indonesia. Situs VitePress ini memuat 9 bagian dan 21 bab.

## Menjalankan secara lokal

Dari root repository:

```bash
npm install
npm run dev:nextjs
```

Buka alamat localhost yang ditampilkan VitePress. Untuk memeriksa hasil produksi:

```bash
npm run build:nextjs
npm run preview:nextjs
```

Naskah sumber tetap tersimpan pada `struktur-ebook-nextjs.md` dan berkas `Ebook Next.js 14 — Bagian *.md`. Halaman situs yang dibaca VitePress berada di `bagian-1/` hingga `bagian-9/`.
