# Ebook Vue.js

Dokumentasi Vue 3 dalam Bahasa Indonesia. Situs VitePress ini memuat 7 bagian dan 24 bab.

## Menjalankan secara lokal

Dari root repository:

```bash
npm install
npm run dev:vue
```

Buka alamat localhost yang ditampilkan VitePress. Untuk memeriksa hasil produksi:

```bash
npm run build:vue
npm run preview:vue
```

Naskah asal tetap tersimpan di `docs/vue js/`. Halaman VitePress yang dibaca pengunjung berada di `docs/vue/bagian-1/` hingga `docs/vue/bagian-7/`.
